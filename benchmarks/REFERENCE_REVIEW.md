# Reference review record

Status: **awaiting independent human review**.

The synthetic design reference was constructed programmatically and checked by an agent. No human approval is implied by its inclusion in the repository.

A human reviewer should inspect [the source image](../examples/shapes.png), [the reference](reference.json), and [accepted label aliases](aliases.json), then submit a PR recording:

- Reviewer name or public handle and date.
- Reviewed image SHA-256 and reference commit.
- Whether all visible shapes are represented and correctly named.
- Whether the coordinate/raster boundary convention is appropriate.
- Corrections, uncertainties, or approval.

Keep prior review records when changing the reference. Score changes caused by a reference revision should be reported separately from changes caused by a model or harness.
